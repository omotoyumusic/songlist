# ソングリスト

曲のキー、歌唱履歴、備考をユーザーごとに管理するWebアプリです。曲データはSupabaseに保存し、GitHub Pagesはアプリ本体の公開に使用します。

## 使い方

- メールアドレスで会員登録・ログインし、アーティストと曲名、それぞれの読み、原曲キー、移調、備考を登録します。曲の編集、削除、同じアーティストの曲の追加、アーティスト名の一括変更に対応します。
- キーは曲ごとに複数の設定を保存でき、移調後のキーと平行調を表示します。
- 「今日歌った」と「歌唱履歴」で記録を追加・修正・削除できます。過去の最終歌唱日は既知の1回として扱います。
- 「歌唱の振り返り」では月別の回数・曲数、よく歌った曲やアーティストを確認できます。
- 読み仮名・曲名・アーティスト等で検索でき、アーティスト・歌唱日での絞り込み、歌唱回数順などの並び替えに対応します。五十音インデックスはアーティスト順と曲名順で利用できます。
- 検索メニューからChordwiki、YouTube、カラオケ、コード譜、歌詞、作詞作曲、Wikipediaを検索できます。「楽曲情報」にはWikipediaの作詞・作曲・編曲とAppleの配信情報を表示します。Appleの候補はアーティスト名が一致するものを優先し、一致しない候補はその旨を表示します。発売年は作品やアルバムの年で、初発売年とは限りません。J-WIDの管理情報はログイン後のみ確認できます。
- 個人用の変更はSupabaseに保存し、CSVでバックアップ・復元できます。CSVの「追加データ(JSON)」には歌唱履歴とキー設定も含まれます。端末には未保存の変更を下書きとして保持し、別端末での競合を検知します。

## 閲覧用URL

ログイン後に共有設定を開き、閲覧用URLをコピーできます。URLを知る人はログインせずに、表示設定を有効にした曲の検索・閲覧、歌唱回数の確認と月別の振り返りができます。共有の停止とURLの再発行も可能です。

閲覧用には曲名、アーティスト、検索・並び替え用の読み、選択中のキー、最後に歌った日、歌唱回数と月別回数を提供します。備考、非表示曲、最後に歌った日以外の履歴の詳細、キー設定名は含めません。読み仮名は閲覧画面には表示せず、検索と並び替えに使います。

## 構成と新規環境の設定

1. Supabaseプロジェクトでメール認証を設定し、登録確認・パスワード再設定の送信先とリダイレクトURLを設定します。実際のメール送信にはSMTPの設定と各サービスの送信制限を確認してください。
2. 次のSQLを順に適用します。過去の移行ファイルも既存環境の復旧と再構築に必要です。
   - `20261012000000_user_song_lists.sql`
   - `20261013000000_public_song_list_shares.sql`
   - `20261017000000_safe_song_lists.sql`
   - `20261103000000_public_singing_count.sql`
   - `20261104000000_public_singing_review.sql`
3. `config.js` にSupabaseのURLと公開用のanon / publishable keyを設定します。サービスロールキーや個人アクセストークンをブラウザーに置かないでください。
4. `delete-songlist-account` と `songlist-work-info` をSupabase Edge Functionsにデプロイします。アカウント削除はサーバー側でログインユーザーを確認します。
5. アプリをGitHub Pagesに公開します。アプリの公開にGitHubを使いますが、曲リストはGitHubへ同期しません。

データベースでは `get_my_song_list` / `save_my_song_list` が本人のデータを取得・保存し、保存時には変更番号を照合します。共有の取得は `get_public_song_list`、共有の開始・停止等は `manage_my_song_share` を使用します。共有用の読み仮名・並び順を維持するための情報は保存時に更新します。

## 表示と動作確認

曲の一覧は先頭を先に表示し、残りを少しずつ自動表示します。検索と五十音インデックスは全曲を対象にします。画面幅700px以下はカード表示、それより広い場合は表を表示します。

自動チェックはアプリのディレクトリで以下を実行します。模擬データを使い、実際の曲リストやアカウントは変更しません。

```sh
node test-songlist.cjs
node test-account.cjs
```
