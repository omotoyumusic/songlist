# ソングリスト

曲とキーを管理するWebアプリです。最初に新規登録またはログインし、ログイン後は自分専用のリストを表示します。共有リンクを知っている人は、そのユーザーが閲覧用に公開した曲だけを見られます。

## 主な機能

- ユーザーごとに分離された曲リスト、備考、CSV入出力
- アーティスト名・曲名の読み仮名順検索と並べ替え
- 原曲キー、自分が歌うキー、平行調、最終歌唱日の記録
- ユーザーごとに異なる閲覧専用リンク
- 閲覧リンクには「一覧に表示する」を有効にした曲だけを含め、備考は含めません

## Supabaseの設定

1. SupabaseのAuthenticationでメール登録を有効にします。
2. SQL Editorで [`20261012000000_user_song_lists.sql`](20261012000000_user_song_lists.sql) を実行します。個人の曲リストはログイン中の本人だけが読み書きできます。
3. 続けて [`20261013000000_public_song_list_shares.sql`](20261013000000_public_song_list_shares.sql) を実行します。閲覧リンクは専用RPCから共有IDのリストだけを返し、共有テーブル全体の検索は許可しません。
4. `config.js` のSupabase Project URLと公開用 anon / publishable keyを設定します。service-role keyやGitHub tokenはブラウザー側へ置かないでください。
5. アプリをGitHub Pagesへ公開し、最初の画面からユーザー登録またはログインします。

```js
window.SONGLIST_CONFIG = {
  supabaseUrl: "https://YOUR_PROJECT.supabase.co",
  supabaseAnonKey: "YOUR_PUBLIC_ANON_OR_PUBLISHABLE_KEY"
};
```

既存の617曲はオーナーの `song_lists` に引き継ぎ済みです。新しいユーザーは空の個人リストから始めます。曲リスト自体はGitHubへ同期しません。

## 閲覧リンク

ログイン後に「URLをコピー」を押すと、推測しにくい共有IDを含むユーザー固有のURLを作成します。リンクを開くと、そのユーザーの公開設定済み曲を読み取り専用で閲覧・検索できます。ログイン中でも共有URLでは編集できません。

## CSV

- CSVの書き出し・取り込みはログイン後に利用できます。
- 「追加・更新する」はアーティスト名と曲名が一致した行を更新します。「すべて置き換える」は自分のリストだけを置き換えます。
- 添付CSVの初期データは617曲です。元CSVに読み仮名全体がない曲は、読みを編集して補完してください。
